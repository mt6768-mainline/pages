== Kernel
1. Copy merlin devicetree and rename to match `mt6768-vendor-codename.dts`.
2. Add your new `.dtb` target to `arch/arm64/boot/dts/mediatek/Makefile`.
3. Remove every i2c, spi, dsi, regulator and other nodes. Make sure to keep only uart, pio and usb.
4. Once it boots, go port TF-A and U-Boot.
5. Then start adding more nodes, until eventually the functionality is similar to merlin.
6. Do *NOT* bring SCP stock firmware for sensors. Instead, merlin re-muxes i2c and spi to the AP, so you should do the same.
7. Do *NOT* add panel-simple after bringup is done. Switch to proper panel driver.

== U-Boot & TF-A
You have to replace both at the same time, because TF-A doesn't provide SiP calls for stock LK, and U-Boot is 64-bit, which doesn't work with stock blobs because they assume BL32 is 32-bit.

For TF-A, there's no porting in general at all. You just build it and flash. That's it.

For U-Boot, it's usually similar to Linux. Take the Linux DT, adapt to U-Boot, following merlin as example. It's usually easier to port Linux display first, then U-Boot is simply adapting panel and backlight from Linux drivers.
