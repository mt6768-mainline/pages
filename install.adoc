== Install
Flash TF-A:
[,shell]
----
sudo -E ./mtk.py w tee1 atf.img
----

Flash U-Boot to replace LK:
[,shell]
----
sudo -E ./mtk.py w lk uboot.img
----

Flash U-Boot to chainload as kernel:
[,shell]
----
sudo -E ./mtk.py w boot uboot.img
----
